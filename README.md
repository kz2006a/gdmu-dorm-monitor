# 广东医宿舍水电查询 · v0.2.0

Python 图形窗口版：手动提供自己的 Token，依次选择校区、楼栋和房间，查询所选宿舍的剩余电量、水量。

## 安装与启动

```powershell
python -m pip install -r requirements.txt
python run.py
```

Windows 已安装 Python 和依赖时，也可双击 `启动查询工具.cmd`。

## 使用流程

1. 粘贴自己的 Token，点击“加载宿舍列表”。
2. 依次选择校区、楼栋、房间，点击“查询所选宿舍”。
3. 切换宿舍后旧余量清空，重新查询后显示新宿舍数据。

也可按内部楼栋 ID、房间 ID 查询；它们不是楼号或门牌号。公开版默认示例编号为 1/1，请先选择自己的宿舍。Token 默认遮挡，不保存。

## 本版范围

增加图形界面、三级宿舍列表选择、内部编号查询、后台查询和小窗口滚动。仍需 Python，没有独立 EXE、定时监测、邮件、Windows 通知或自动登录。

## 归档与公开整理

GUI 源码来自保留的历史源码包；启动器改为相对路径/PATH，补齐仓库启动入口、依赖和使用说明。协议样例及界面默认内部编号均改为合成示例，未改变选择/查询业务流程。

项目代码使用 MIT；cryptography 是外部依赖，保留自身许可。请勿上传真实 Token、抓包、私钥或个人配置。
