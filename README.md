# 广东医宿舍水电查询 · v1.7.0

## 启动和查询

完整解压 Windows 程序包，双击其中的 EXE。目录式程序包应保留同级 app、_internal 及 runtime（如有）文件夹。

进入“微信连接”获取有效登录，自动加载宿舍列表。依次选择校区、楼栋、房间；选完保存并查询。下次运行按内部 ID 恢复上次宿舍。

## 提醒设置

默认可使用 Windows 通知，无须填写邮箱。设置水电低阈值、固定提醒时间和监测间隔；查询及网络失败重试最低 30 分钟。需要邮件时另填 SMTP 服务器、端口、连接方式、账号、授权码、发件人和收件人。

配置保存在程序同级 .env。可选择保存凭证和打开软件后自动监测；这些选项不会设置 Windows 开机启动。保存凭证会将 Token 和邮件授权码写入本地文件，请勿分享该文件。

## 微信连接

在连接页面配置小程序快捷方式，按界面操作准备专用证书并连接本地代理。新 Token 由真实微信小程序登录产生；微信可能需要手动完成学校登录或进入查询页。软件不会生成虚拟登录 code。操作结束后可用恢复网络功能撤销本软件设置的代理。

## 使用范围

数据以上游学校系统为准，仅查询自己有权使用的宿舍。最小化可继续运行；退出或休眠期间不能监测。个人配置、登录响应和证书私钥不随公开包分发。

## 从源码运行

```powershell
python -m pip install -r requirements.txt
python run.py
```

公开源码来自保留的历史源码目录，补齐相对路径启动入口和使用说明。协议样例及默认示例编号使用合成数据。
