# 广东医宿舍水电查询 · v1.0.0

## 启动和查询

完整解压 Windows 程序包，双击其中的 EXE。目录式程序包应保留同级 app、_internal 及 runtime（如有）文件夹。

填写自己的有效 Token，加载宿舍列表，依次选择校区、楼栋、房间并查询。切换宿舍后重新查询以显示对应余量。

## 使用范围

数据以上游学校系统为准，仅查询自己有权使用的宿舍。最小化可继续运行；退出或休眠期间不能监测。个人配置、登录响应和证书私钥不随公开包分发。

## 归档来源

本版本仅保留原始独立 EXE，没有独立保存的原始 Python 源码。源码参考相邻 v0.2.0 标签；该参考代码不代表本版原始源码。

历史单文件 EXE 保留原始字节，包含当时的非凭证协议样例和构建元数据；源码包中的离线样例另行使用合成数据。
