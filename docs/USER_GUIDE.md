# 广东医宿舍水电查询 · v1.2.0

## 启动和查询

完整解压 Windows 程序包，双击其中的 EXE。目录式程序包应保留同级 app、_internal 及 runtime（如有）文件夹。

填写自己的有效 Token，加载宿舍列表，依次选择校区、楼栋、房间并查询。切换宿舍后重新查询以显示对应余量。

## 提醒设置

在邮件设置填写 SMTP 服务器、端口、连接方式、账号、密码或授权码、发件人和收件人。可先发测试邮件，再设置固定提醒时间、余量阈值及查询间隔，开始提醒。

配置保存在程序同级 .env。可选择保存凭证和打开软件后自动监测；这些选项不会设置 Windows 开机启动。保存凭证会将 Token 和邮件授权码写入本地文件，请勿分享该文件。

## 使用范围

数据以上游学校系统为准，仅查询自己有权使用的宿舍。最小化可继续运行；退出或休眠期间不能监测。个人配置、登录响应和证书私钥不随公开包分发。
